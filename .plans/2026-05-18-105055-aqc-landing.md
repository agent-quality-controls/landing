# Goal

Build the agent-qc landing site in this repository by copying the WebSmasher Astro landing app and shared UI package, then adapting the design through existing tokens and shared components.

# Approach

- Copy the WebSmasher root workspace files needed for a standalone landing workspace.
- Copy `apps/landing` and `packages/ui` source/config files, excluding generated folders and build output.
- Replace WebSmasher brand, URL, content, and assets with agent-qc values.
- Recolor and refont existing `packages/ui/globals.css` tokens before creating any new token.
- Bin Claude design sizes to existing type, radius, spacing, and utility tokens wherever possible.
- Reimplement the two pages:
  - `/`
  - `/manifesto/`
- Keep routes thin: load typed content, build metadata and JSON-LD, render UI components.
- Keep hardcoded Tailwind to layout-only code where possible.
- Run validation and build checks.

# Key Decisions

- Astro remains the landing framework.
- `@project/ui` remains the design-system package.
- Claude output is a visual and copy reference only, not copied runtime architecture.
- New design tokens require an explicit audit entry showing why existing tokens are insufficient.
- Existing terminal/code tokens should cover terminal surfaces unless implementation proves a gap.

# Files To Modify

- Root workspace config files.
- `apps/landing/**`
- `packages/ui/**`
- Public brand assets under `apps/landing/public`.

# Design-System Audit Rule

Before adding a new token or shared component, record:

- proposed name
- existing token/component considered
- reason existing option is insufficient
- exact call sites

# Design-System Audit Result

- New token names added: none.
- `--surface` from Claude maps to existing `--card`.
- `--surface-2` from Claude maps to existing `--fill-muted` for cards and `--surface-code-elevated` for terminal/code panels.
- `--terminal-bg` maps to existing `--surface-code`.
- `--terminal-elevated` maps to existing `--surface-code-elevated`.
- `--terminal-fg` maps to existing `--surface-code-foreground`.
- `--terminal-border` maps to existing `--surface-code-border`.
- `--terminal-prompt` and `--terminal-cursor` map to existing `--accent`.
- Claude's 13px body size is binned to existing `--text-body-sm`.
- Claude's 40px section heading is binned to existing `--text-section-lg`.
- Claude's 88px hero is binned to existing `--text-display-2xl`.
- Existing utility classes reused: `ui-page-shell`, `ui-section-shell`, `ui-section-eyebrow`, `ui-mono-label`, `ui-status-pill`, `ui-status-pill-dot`, `ui-accent-dot-grid`, `ui-metric-xl`.
