# Summary

Implemented the Agent QC Astro landing app from the WebSmasher landing and UI package scaffold. Replaced SEOChecks/WebSmasher content with Agent QC homepage and manifesto pages, copied the Agent QC design assets, and adapted the existing UI token system to the Agent QC colors, fonts, type scale, and tighter radii.

# Decisions Made

- Reused the existing WebSmasher token names instead of adding new tokens. Claude design values were mapped into existing color, type, radius, spacing, and surface bins.
- Kept page-specific layout in the landing app and shared primitives in `packages/ui`.
- Converted the provided PNG logo to WebP for rendered page usage while keeping generated favicon PNG/ICO files.
- Removed blog, MDX, locale routing, and R2 image plumbing because the site now has only `/` and `/manifesto/`.
